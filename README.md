# Personal Dev Projects

A collection of my personal development projects — hobby builds, home automation, and tools for day-to-day life. Each project has its own plan document with phased steps, code snippets, and checklists to follow.

---

## Projects

### 1. [Personal Media Server](./media-server-project-plan.md)
A home media server built on an old laptop running Ubuntu, Jellyfin, and qBittorrent — with Sonarr and Radarr for automated downloads and Tailscale for remote access from anywhere.

**Effort:** 1–2 weekends

---

### 2. [Media Server App](./jellyfin-app-project-plan.md)
A custom Netflix-style React Native app that connects to the media server, targeting two platforms from a single codebase — an Amazon Firestick for the TV and Samsung Galaxy phones.

**Effort:** 3–5 weekends

---

### 3. [AI Home Assistant](./home-assistant-project-plan.md)
A custom AI-powered voice assistant built on a spare Amazon Echo. The Echo handles the audio pipeline natively; a custom Alexa Skill routes commands to a local Python server powered by the Claude API, exposed via Cloudflare Tunnel.

**Effort:** 2–3 weekends

---

## Notes

These are personal projects built for learning and home use. Plans are written to be followed in phases so early stages produce something working, with polish added iteratively. All three projects can be worked on concurrently without conflicts.
